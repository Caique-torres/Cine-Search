# CineSearch

Uma aplicação web de busca de filmes desenvolvida com HTML, CSS e JavaScript, criada para pesquisar filmes e apresentar informações utilizando a API de filmes.

## Demonstração

[Clique aqui para acessar o CineSearch](https://caique-torres.github.io/Cine-Search/)

## Funcionalidades

- Busca de filmes
- Pesquisa por nome do filme
- Integração com a API OMDb
- Exibição de filmes encontrados
- Posters dos filmes
- Título dos filmes
- Ano de lançamento
- Tipo do conteúdo
- Visualização dos detalhes do filme
- Modal com informações do filme
- Exibição da sinopse
- Tradução da sinopse para português
- Mensagem durante o carregamento
- Mensagens de erro
- Tratamento de filmes sem poster
- Interface responsiva
- Layout adaptado para dispositivos móveis
- Fechamento do modal
- Fechamento do modal ao clicar fora
- Fechamento do modal utilizando a tecla ESC

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API OMDb
- API MyMemory

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com criação de interfaces web, responsividade, manipulação do DOM, eventos, formulários, requisições HTTP e consumo de APIs.

O projeto também foi desenvolvido para simular uma plataforma de busca de filmes, permitindo pesquisar títulos, visualizar posters, consultar informações dos filmes e visualizar suas respectivas sinopses.

A integração com a API do OMDb permite obter informações dos filmes, enquanto a API de tradução é utilizada para apresentar as sinopses em português.
